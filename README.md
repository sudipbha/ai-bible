# Reading copy

A rendered, mobile-friendly reading copy of a book in progress:
**The AI Guide for Small Business**.

- Read it: https://sudipbha.github.io/ai-bible/
- This repo contains only the generated `index.html`. The manuscript sources,
  research files, and working notes live in a private repository.
- `index.html` is generated by a build script in that private repo. Do not edit
  it here; edits would be overwritten on the next sync.

## Read aloud

Open any available chapter and tap the play button in the top bar. The reader
supports play/pause, previous and next sentence, sentence seeking, 0.5–3×
speed, saved position, synchronized highlighting, and phone media controls.

The default narration is Ash, an AI-generated OpenAI voice. Audio is generated
privately during the release build and published as fixed chapter assets under
`audio/`; no API key or paid API call exists in the browser. If a matching Ash
asset is unavailable, the reader falls back to a voice provided by the device.
