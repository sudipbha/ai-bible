## Sizes
Apple requires screenshots for at least one current large iPhone display size; check the current list
in App Store Connect Help ("Screenshot specifications") on the day. The CI screenshots come from an
iPhone SE simulator (smaller size) with synthetic text, so they are **previews only, not store assets**.

## How to take them
On a Mac, run the real-book build in the Simulator on the required device size, add a few sample
decisions, and use File → Save Screen (⌘S). Don't show private customer data.
